## Projetos Ativos

### Jarvis — Construction Intelligence OS

| Campo | Valor |
|-------|-------|
| Pasta | `brav_digital/jarvis/` |
| Status | Em desenvolvimento |
| Stack | Agno + Claude Sonnet + PostgreSQL + WhatsApp API |
| Responsável | Brav Digital |

**Descrição:** SaaS multi-tenant de IA para lojas de materiais de construção. Cada loja tem seu próprio agente inteligente com suporte a estoque, marketing, WhatsApp, análise de projetos e relatórios.

**Agentes:**
- Inventory Agent — alertas de estoque e sugestões de reposição
- Marketing Agent — campanhas no WhatsApp e segmentação de clientes
- WhatsApp Agent — atendimento ao cliente e consulta de produtos
- Projects Agent — análise de PDFs arquitetônicos e orçamentos
- Reports Agent — relatórios executivos diários/semanais/mensais
